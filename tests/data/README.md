# Выборка для теста качества

`model_quality.npz` содержит `X` (180 окон × 48 шагов × 3 признака) и `y`
(метки классов). Это тестовая выборка из раздела «Данные и независимые выборки»
ноутбука `artifacts/tiny_sequence_transformer.ipynb`: генерация с seed=42,
затем два стратифицированных разбиения с random_state=42.
Обучающая и валидационная выборки в файл не включены.

Тест загружает готовые данные и сравнивает F1 с `metadata.test_metrics.f1`
сохранённой модели (1.0).
